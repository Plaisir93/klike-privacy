# Klike — privacy policy

The privacy policy for **Klike**, a free offline app that teaches computer
skills in Haitian Creole, published by EBOLD.

Served by GitHub Pages: <https://plaisir93.github.io/klike-privacy/>

This repository holds the published page only. The page is written in Haitian
Creole and English, with a toggle, and is the URL given to the App Store and
Google Play.

Source of truth: `privacy/index.html` in the Klike app repository. Edit it
there, then copy it here.
